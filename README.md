# Costruire la mente

Animazioni introduttive per la presentazione sul **neurocostruttivismo**: dal dibattito tra innatismo ed empirismo (Platone, Aristotele, Rousseau, i test d'intelligenza) a Piaget, fino alla potatura sinaptica.

## File

| File | Cosa è |
|---|---|
| `index.html` | Pagina iniziale: sceglie tra le due versioni |
| `versione-breve.html` | Introduzione di circa un minuto, con voce registrata (incorporata nel file) e sottotitoli di riserva |
| `versione-completa.html` | Versione lunga, circa 3 minuti, con didascalie |
| `discorso-breve.md` | Testo della voce, con indicazioni per la lettura |
| `scritte-breve.md`, `scritte-completa.md` | Copioni delle due versioni |

## Come si usa

Apri il link di GitHub Pages, oppure scarica il file e aprilo con un doppio clic in Chrome o Safari.

Nella versione breve:
1. **Prova la voce** → si sente la prima frase.
2. **Lo senti?** → *Sì, inizia* (con la voce) · *Riprova* · *No, usa i sottotitoli*.

Comandi: **→** scena successiva · **←** scena precedente · **spazio** pausa · **Reset** (in alto a sinistra) torna all'inizio.

Ogni file è autonomo: non servono installazioni né connessione a internet.
